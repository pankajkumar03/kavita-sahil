# Photos

Drop your photos here with exactly these names (or change the paths in
`src/config/invitation.ts`). Any photo that is missing shows a soft
placeholder, so you can add them one at a time.

| File | Used for | Suggested size |
| --- | --- | --- |
| `hero.jpg` | Large arched photo at the top | 1200 × 1500 (portrait) |
| `bride.jpg` | Bride's portrait, "A Beautiful Beginning" | 900 × 1200 (portrait) |
| `groom.jpg` | Groom's portrait | 900 × 1200 (portrait) |
| `gallery-1.jpg` … `gallery-6.jpg` | "Moments Before the Celebration" (up to 12) | 1600px on the long side |
| `og-cover.jpg` | Preview image when the link is shared on WhatsApp | exactly 1200 × 630 |

Keep each JPG under ~400 KB (squoosh.app works well) so the invitation
opens quickly on mobile data.
